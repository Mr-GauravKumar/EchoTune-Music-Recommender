# 🎵 EchoTune - Music Recommendation System

EchoTune is a modern music recommendation system built using Machine Learning and Streamlit.  
It recommends similar songs based on cosine similarity and provides a clean interactive UI experience.

---

## 🚀 Features

- 🎧 Song Recommendation System
- 🔥 Similarity Percentage
- 👨‍🎤 Artist Information
- 🎲 Dynamic Recommendations
- 🌌 Modern Dark UI
- ⚡ Fast Recommendation Engine

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## ▶️ Run Locally

Clone the project:

```bash
git clone https://github.com/YOUR_USERNAME/EchoTune-Music-Recommender.git
```

Go to the project directory:

```bash
cd EchoTune-Music-Recommender
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## 🧠 Recommendation Technique

This project uses:

- TF-IDF Vectorization
- Cosine Similarity

to recommend songs similar to the selected song.
